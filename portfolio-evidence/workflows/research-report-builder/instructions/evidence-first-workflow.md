# Evidence-first report workflow

1. Frame the decision, reader, scope, jurisdiction, period, output, and exclusions.
2. Choose a report archetype instead of forcing one outline.
3. Stage the brief, source log, evidence matrix, source folder, report skeleton, and exhibits folder.
4. Research baseline facts, current developments, drivers, contrary evidence, and implications in separate passes.
5. Link every material claim to a dated source and record whether it needs refresh.
6. Draft from the evidence matrix.
7. Build exhibits only where they clarify a relationship.
8. Reconcile data cutoffs, citations, narrative, charts, and metadata before release.

The workspace scripts create controls; they do not perform or verify the research.
