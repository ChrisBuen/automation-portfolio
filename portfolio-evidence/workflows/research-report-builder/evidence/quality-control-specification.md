# Quality decision specification — research report production

## Decision tree

| Gate | Pass condition | Failure or uncertainty route | Evidence created |
| --- | --- | --- | --- |
| Brief and archetype | Decision, audience, scope, cutoff, and report structure are explicit | Narrow or restate the assignment | Research brief and outline architecture |
| Source quality and freshness | Material claims use the strongest available current sources; data gaps are disclosed | Research further, replace source, narrow claim, or state the gap | Source log with dates and limitations |
| Claim support | Every important claim maps to evidence; facts, estimates, inference, and contested claims are labelled correctly | Return unsupported claim to the evidence matrix | Claim/evidence matrix and citation record |
| Opposing-evidence pass | Contrary evidence and alternative mechanisms have been tested | Revise thesis, confidence, or scope | Counter-evidence notes and caveats |
| Exhibit defensibility | Each chart proves one point and has date, units, source, and reproducible data | Use a table/note, rebuild the chart, or remove it | Cached data and chart manifest |
| Data-pattern verification | Visible spikes, troughs, and regime changes reconcile to the source series | Investigate source noise; do not invent a narrative | Verification note and corrected exhibit |
| Chart visual QA | No clipping, collision, illegible legend, misleading scale, or inconsistent styling | Fix and regenerate the affected chart set | Inspected chart set and issue log |
| Narrative quality | Sections contain evidence, mechanism, implication, balance, and decision relevance | Research or rewrite; scaffolding is not treated as a report | Full draft and editorial notes |
| Cross-artifact reconciliation | Text, citations, tables, charts, dates, and source lines agree | Return to the responsible source, claim, or exhibit | Reconciled report package |
| Publication QA | DOCX/PDF structure and every rendered page pass review | Rebuild final output after any chart or layout change | Release record, DOCX/PDF, update package |

## Controls that demonstrate quality

- Report structure follows the decision, not a generic template.
- Weak evidence changes the claim language or removes the claim; confidence is not manufactured.
- Research runs in baseline, current-development, opposing-evidence, and implication passes.
- Data is cached before chart production so rerenders remain reproducible.
- Charts are evidence artifacts with a point to prove, not decoration.
- Any chart revision forces the final document to be rebuilt and reinspected.
