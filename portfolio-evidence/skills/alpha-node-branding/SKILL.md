## What this skill does

This skill converts an approved content artifact into recognisable Alpha Node material without improvising the identity. It selects the correct bundled assets, applies the documented logo, colour, type, spacing, and layout rules, adapts composition to the output medium, and checks that institutional financial-services tone survives through final rendering.

## Core Workflow

1. Read `references/brand-guidelines.md` before making design decisions.
2. Use only identity assets that the rights holder has supplied and approved for the specific output.
3. Apply the machine-readable controls in `references/brand-tokens.json`.
4. Render the completed artifact and validate it against the checklist in this file before delivery.

## Brand Foundation

Present Alpha Node as a regulated, transparent, modern digital-asset finance brand for institutional and high-net-worth investors. Favor confident, precise language around regulated financial products, digital asset investing, staking, custody/storage, and future-facing finance.

Do not reuse placeholder text from the source brand book. Some pages contain Lorem Ipsum and should be treated as layout placeholders only.

## Essential Visual Rules

- Use official logo files only. Do not recreate, stretch, slant, recolor, warp, add transparency, or apply visual effects to the logo.
- Preserve the logo aspect ratio exactly in every output. Scale logos proportionally from corners or by locked width/height constraints only.
- Maintain clear space around the logo equal to at least the logo height on all sides.
- Use high contrast between logo and background. Use positive, negative, black, white, or all-white variants as context requires.
- Use the core palette consistently: Pantone 302 `#004165`, Pantone 298 `#00B7E4`, Pantone Magenta `#D33982`, Pantone 296 `#031E2F`, and white.
- Use Futura PT for headings and body copy when available. Use bundled Gilmer fonts only when a local fallback or logo-adjacent display style is needed.
- Use mono slate/dark blue treatments, crisp geometry, and restrained magenta/cyan accents. Avoid casual, playful, rustic, or overly decorative styling.

## Output Guidance

For documents and PDFs, create a polished financial-services layout: strong cover page, clear section hierarchy, ample margins, dark blue headers or dividers, restrained accent color, and logo placement that respects clear space.

For PowerPoint, prefer dark title slides, high-contrast section dividers, data-heavy slides with clean grids, and reusable footer/header treatment. Use brand graphics as accents, not background clutter.

For web pages, make the product or brand immediately visible in the first viewport. Use the logo, slate palette, Futura/Gilmer typography, and clean institutional layouts. Avoid generic stock-like visuals when actual brand assets can carry the page.

For social and banners, prioritize legibility at small sizes. Use simple compositions, one primary message, and verified logo contrast.

## Validation Checklist

Before finishing, check:

- Logo is official, proportionally scaled, unstretched, high contrast, and has clear space.
- Colors match the brand tokens and are not approximated.
- Typography uses Futura PT or an acceptable fallback.
- Output reads as regulated finance, not generic crypto, gaming, or startup promotion.
- Any copied source text has been checked for placeholders.
- Final files include the required assets rather than external links to this skill folder.
